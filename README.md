# Student Management System

A simple C++ project demonstrating:
- Classes and Objects
- Default and Parameterized Constructors
- Encapsulation
- Single Inheritance
- Function Overriding

## Classes Used

- Person: Stores the name and age of a person.
- Student: Inherits Person and stores roll number and department.

## How to Compile

Make sure you have a C++ compiler (G++) installed.

Run:

```bash
g++ main.cpp -o student
